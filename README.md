## What is AIRegistry?

AI projects repeatedly rebuild the same small building blocks:

- retrieval
- memory
- agent loops
- citations
- chat starters
- reusable tools

AIRegistry packages these building blocks as **small, readable, auditable source components**.

Search one.

Inspect it.

Add it.

Own the source.
